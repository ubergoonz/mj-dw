# 秋後算績 (Player Results)

Track a play session's chip counts and settle net win/loss between players.

Route: [`/#/player-results`](https://ubergoonz.github.io/mj-dw/#/player-results)

![Player Results screenshot](/img/features/player-results.png)

## How it works

1. Set the total base chips for the table; Reset session splits this amount evenly across 東、南、西、北.
2. Enter each player's name, base chips, and remaining chips in their seat card.
3. The tool continuously validates base and remaining-chip tallies against the total; mismatches are marked in red.
4. When a player leaves mid-session, enter the replacement name and choose `接手`. The outgoing result is recorded and the incoming player starts with the remaining chips as their new base.
5. At the end of play, enter the remaining chips and use `完場` per seat or `全完場` for every seat.
6. Review the recorded entries and copy (or share, on mobile) the chat-ready summary. A wrong entry can be removed with the `×` on its row and restored with `Undo`.

![秋後算績 records and chat summary](/img/features/player-results-records.png)

## Your session is auto-saved

Everything on this page — chip totals, names, inputs and recorded results — is saved on the device as you type. Locking the phone, switching apps, or reloading the page does not lose the ledger. A banner shows when the current session started. Only `Reset session` clears it, and it asks for confirmation first when there is anything to lose. `全完場` and any record made while the remaining-chip tally does not match the table total also ask for confirmation.

## The calculator shows

- per-seat win/loss: remaining chips minus that player's base
- running record count
- base tally and remaining-chip tally compared with the table total
- total difference, with gain/loss color treatment
- a copyable chat summary of takeovers and final results

## Implementation

- Page: `src/pages/PlayerResults.tsx`
- Logic: `src/lib/playerResults.ts` handles chip tally validation, net calculation, and result entry formatting.
- Persistence: `src/lib/usePersistentState.ts` and `src/lib/storage.ts` keep the session in `localStorage` with shape validation so a stale save can never break the page.
