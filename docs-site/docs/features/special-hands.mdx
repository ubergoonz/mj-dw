# 特別牌型 (Special Hands)

Use this reference to look up common Singapore-style tai values for the special hands used by this toolkit.

Route: [`/#/special-hands`](https://ubergoonz.github.io/mj-dw/#/special-hands)

![特別牌型 screenshot](/img/features/special-hands.png)

## How it works

1. Choose a hand from the Special hand dropdown.
2. Choose `Classic color` (default) or `Unicode` from Tile image set. Your choice is remembered on the device. Future image sets can be added to the shared renderer.
3. Read the tai badge for the selected hand.
4. Review the Mahjong tile-image layout, description, and table-rule note.
5. The final tile has a red border: it is the winning tile that completes the illustrated hand. Check whether your table permits it as a self-draw, a discard claim, or both.
6. Review Other winning potential. Short wait lists display tile images; broad waits, such as 13 Wonders and Nine Gates, are explained in text instead.
7. Confirm the values with your group before play.

## Rule catalogue

The source of truth is [`src/data/specialHands.json`](https://github.com/ubergoonz/mj-dw/blob/main/src/data/specialHands.json). Each entry contains its name, tai value, description, rule note, and example tiles.

Tai values are a convenient Singapore-style baseline rather than universal rules. Update the JSON file as your table agrees additions, removals, or different payouts.

## Tile image sets

- **Classic color** is drawn to match a real Singapore set: concentric-ring 筒 with the traditional green/red/blue placements and the large ornate 一筒; segmented 索 sticks with the bird 一索; a blue numeral over a red 萬 (with 伍 for five); blue 東南西北; red 中, green 發, and a double-framed 白; 春夏秋冬 and 梅蘭菊竹 with their numerals; and the Singapore animals 貓 鼠 雞 蜈蚣. Characters use the device's CJK serif font, so the calligraphy may differ slightly between phones while colours and layouts stay the same.
- **Unicode** uses the Mahjong Tiles Unicode block, rendered with the device's emoji font.
