# 花獸槓計算 (Side Bets)

Use the side-bet calculator to settle 花/獸 (flower/animal) and 槓 (kong) payments outside the main hand.

Route: [`/#/side-bets`](https://ubergoonz.github.io/mj-dw/#/side-bets)

![花獸槓計算 screenshot](/img/features/side-bets.png)

## How it works

1. Pick a base minimum from 0.5 to 50; the maximum is automatically double the minimum.
2. Review the complete table of 花、獸, and 槓 side-bet rows.
3. 正暗 (hidden) pairs use the maximum value; 正明 (open) pairs use the minimum value.
4. Extra pairs of the same bet type multiply the payout.
5. For open 槓, use the separate 出銃 column to check the amount a single discarder pays.
6. Each player payment row represents what Player A, Player B, and Player C each pay to the winner.

## The calculator shows

- base minimum and maximum values
- the min/max reference for 正明 and 正暗
- per-player payments for each side-bet combination
- the single-payer 出銃 amount where 包 applies
- the winner's total received for that row

## Implementation

- Page: `src/pages/SideBets.tsx`
- Logic: `src/lib/sideBets.ts` handles 花/獸/槓 side-bet row generation and payout amounts.
