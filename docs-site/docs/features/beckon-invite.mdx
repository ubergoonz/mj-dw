# 招兵買馬 (Beckon Invite)

Organize and invite players to a session. The organizer fills in event info and game rules, and the page generates a copy-ready invite text for chat.

Route: [`/#/beckon-invite`](https://ubergoonz.github.io/mj-dw/#/beckon-invite)

![招兵買馬 screenshot](/img/features/beckon-invite.png)

## Event info
- Venue - enter a name or address; the page generates a clickable Google Maps search link
- Expected start and end date + time
- Total hours - automatically calculated from start and end
- Expected number of rounds
- Parking availability
- Smoking availability
   - Yes, at table
   - Yes, outside
   - No, smoker not welcome

## Game rules

- Stake size
   - 0.10 / 0.20
   - 0.20 / 0.40
   - 0.30 / 0.60
   - 0.30 / 0.60 (round off)
   - 0.50 / 1.00
   - 1.00 / 2.00
   - 2.00 / 4.00
   - 3.00 / 6.00 (round off)
   - 5.00 / 10.00
   - 10.00 / 20.00
- Minimum fan: 0-10
- Maximum fan: 1-10 (must be greater than minimum fan)
- Shooter: Yes / No
- 平胡 (Ping Hu): 3.5 / 4
- 花獸咬 (Animal/Flower Bite): Yes / No
  - Open bite:
      - 正：Yes / No
      - 臭：Yes / No
  - Close bite:
      - 正：Yes / No
      - 臭：Yes / No
- End Wall: 7.5 / Play all
- 門清 Conseal
   - [ ] Not played (不設)
   - [ ] Play
   - [ ] Play + 1 台
- Dice Bonus: Yes / No
   - Bonus type: free text, shown when Dice Bonus is enabled

### Special hands

- 大三元:
   - [ ] Not played (不設)
   - [ ] Winning hand only (和牌才算)
   - [ ] Pong/Kong all 3 dragons (碰/槓三元即成)
- 大四喜:
   - [ ] Not played (不設)
   - [ ] Winning hand only (和牌才算)
   - [ ] Pong/Kong all 4 winds (碰/槓四喜即成)
- 七对子：
   - [ ] 有玩 
   - [ ] 沒有玩 
- 花胡：有玩 / 沒有玩 (played or not)
   - [ ] 有玩 played:
      - 自摸第 7 張可搶第 8 張，抓第 8 張者付 1 台出銃 + 2 台閒家
      - 自摸第 8 張，全體以出銃價支付
   - [ ] not played:
      - 自摸可打到第 7 張，第 8 張仍可搶（付 1 台）
- 天地胡
   - 僅限首圈
   - 天胡： 限庄家，全體以出銃價支付
   - 地胡： 自摸第 7 張可搶第 8 張，抓第 8 張者付 1 台出銃 + 2 台閒家

- Logic: `src/lib/beckonInvite.ts` handles total-hours calculation, the Google Maps link, fan-range validation, and the copy-for-chat invite text generator.
