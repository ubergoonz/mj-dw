# 選風打位 (Wind Draw)

Use the animated compass draw to assign the four winds and determine the dealer before the game starts.

Route: [`/#/wind-draw`](https://ubergoonz.github.io/mj-dw/#/wind-draw)

![選風打位 screenshot](/img/features/wind-draw.png)

## How it works

1. Tap the center `發` tile to start the draw.
2. The app shuffles 東、南、西、北 and reveals the four winds in sequence.
3. Match each revealed wind to the player seated in that compass position.
4. 東 is highlighted as the dealer, with a ▲起莊 marker beside it.
5. Use `再抽一次` to perform a new draw.

## Result

The result panel confirms that 東風 is the dealer. The revealed compass remains visible so everyone can verify the final seating order.

## Implementation

- Page: `src/pages/WindDraw.tsx`
- Logic: `src/lib/winds.ts` handles wind shuffling for seat draw.
