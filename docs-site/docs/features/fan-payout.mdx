# 台數計算 (Tai Payout)

Use the tai payout calculator to review the table payout for every 台 value in a selected range.

Route: [`/#/fan-payout`](https://ubergoonz.github.io/mj-dw/#/fan-payout)

![台數計算 screenshot](/img/features/fan-payout.png)

## How it works

1. Select the base pair: `player / shooter`. The default is `1 / 2`.
2. Set the minimum and maximum 台; the default range is 1-5.
3. The maximum must be greater than the minimum; invalid ranges are highlighted.
4. Optionally enable `Include 自摸 bonus` and enter the bonus amount paid by each player.
5. Review every row in the selected range, including normal-win and 自摸 amounts.

## The calculator shows

- the selected base pair and active 台 range
- normal-win payments from each other player and the shooter
- the winner's total for a normal win
- 自摸 amount paid by each player and the winner's 自摸 total
- optional 自摸 bonus included in each applicable payment

This is designed for quick Singapore mahjong table checks and local-rule comparisons.
