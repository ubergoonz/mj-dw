# 麻将都Win (mj-dw)

麻将都Win is a set of multiple useful utilities for organizing and playing Singapore style mahjong.

Open the live app: https://ubergoonz.github.io/mj-dw/

## Features

- [選風打位](./features/wind-draw.mdx) — determine seat positions before the game starts
- [掷骰子](./features/dice-roll.mdx) — simple 2-dice or 3-dice roller
- [掷骰开墩](./features/in-game-dice-roll.mdx) — in-game wall-break helper
- [番數計算](./features/fan-payout.mdx) — fan payout calculator
- [花獸槓計算](./features/side-bets.mdx) — flower/animal/kong side-bet calculator
- [Player Results](./features/player-results.mdx) — session chip tracking and net settlement
- [招兵買馬](./features/beckon-invite.mdx) — organize a session and generate a chat-ready invite

See the [Features](/docs/category/features) section for details on each tool.
