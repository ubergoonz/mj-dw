# 麻将都Win (mj-dw)

麻将都Win is a mobile-friendly toolkit for organizing and playing Singapore-style mahjong. Each tool is designed for quick table-side use: start a game, break the wall, check payouts, record results, or prepare an invite.

Open the live app: https://ubergoonz.github.io/mj-dw/

## Features

- [選風打位](./features/wind-draw.mdx) — determine seat positions before the game starts
- [掷骰子](./features/dice-roll.mdx) — simple 2-dice or 3-dice roller
- [掷骰开墩](./features/in-game-dice-roll.mdx) — in-game wall-break helper
- [台數計算](./features/fan-payout.mdx) — tai payout calculator
- [花獸槓計算](./features/side-bets.mdx) — flower/animal/kong side-bet calculator
- [秋後算績](./features/player-results.mdx) — session chip tracking, handovers, and net settlement
- [招兵買馬](./features/beckon-invite.mdx) — organize a session and generate a chat-ready invite
- [特別牌型](./features/special-hands.mdx) — tai reference and example winning layouts for special hands
- [清一色听牌](./features/pure-suit.mdx) — single-suit waits, discard suggestions, and known-tile odds

Use the [Features](/docs/category/features) section for the rules, controls, and expected outputs of each tool.

## Using it at the table

### Install it on your phone

The app is installable as a home-screen app. Open https://ubergoonz.github.io/mj-dw/ in your phone's browser and choose **Add to Home Screen** (iOS Safari: Share → Add to Home Screen; Android Chrome: menu → Install app). It launches full-screen with its own 雀 icon.

### Your work is saved on the device

Nothing is sent to a server; the app keeps its state in your browser's local storage so a screen lock, app switch, or page reload does not lose anything:

| Tool | What is remembered |
| --- | --- |
| 秋後算績 | The whole session: total chips, names, per-seat inputs, and every recorded result, until you choose `Reset session` |
| 招兵買馬 | The complete invite form, until you choose `Clear form` |
| 台數計算 | Base pair, 台 range, and 自摸 bonus settings |
| 花獸槓計算 | Base minimum |
| 特別牌型 | Tile image set |
| 掷骰子 | Dice count |

Destructive actions (`Reset session`, `全完場`, recording while the chip tally does not balance) ask for confirmation first.

### Copy and share

Wherever a tool produces chat text, `Copy` places it on the clipboard and shows a brief confirmation. If the browser blocks the clipboard, the app tells you so you can long-press the text instead. On phones a `Share` button also opens the native share sheet.

### Tile images

Tile images follow a real Singapore set: concentric-ring 筒, segmented 索 with the bird 一索, blue numerals over a red 萬, blue winds, red 中, green 發, a framed 白, numbered flowers, and the Singapore animals 貓 鼠 雞 蜈蚣. A plain Unicode style is also available on 特別牌型.
